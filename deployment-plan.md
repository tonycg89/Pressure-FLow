# Render + Supabase Deployment Plan

This is the planned production path for PressureFlow.

## Chosen stack

- Hosting: Render
- Database: Supabase Postgres
- Login: single admin login
- Domain later: `app.yourdomain.com`

## Phase 1: Prepare app for Render

- `package.json` provides `npm start`
- `render.yaml` defines the web service and environment variable names
- Single-admin login is controlled by environment variables

Required Render environment variables:

```text
APP_BASE_URL=https://your-render-url.onrender.com
SESSION_SECRET=<generated by Render>
ADMIN_EMAIL=<your admin email>
ADMIN_PASSWORD=<strong password>
DATABASE_URL=<Supabase connection string, when DB migration is ready>
SQUARE_ENV=sandbox
SQUARE_ACCESS_TOKEN=<sandbox or production token>
SQUARE_LOCATION_ID=<sandbox or production location>
SQUARE_WEBHOOK_SIGNATURE_KEY=<Square webhook key>
GOOGLE_CLIENT_ID=<Google OAuth client ID>
GOOGLE_CLIENT_SECRET=<Google OAuth secret>
GOOGLE_REDIRECT_URI=https://your-render-url.onrender.com/auth/google/callback
GOOGLE_REFRESH_TOKEN=<Google refresh token after connecting Calendar>
GOOGLE_CALENDAR_ID=<calendar ID>
```

## Phase 2: Supabase

Create a Supabase project and run:

```text
supabase-schema.sql
```

PressureFlow now switches to Supabase Postgres automatically when `DATABASE_URL` is set. When `DATABASE_URL` is blank, it keeps using local JSON files.

## Phase 3: Go online

1. Push the project to a GitHub repo.
2. Connect the repo to Render.
3. Add environment variables.
4. Deploy.
5. Update Google OAuth redirect URI to the Render URL.
6. Add Square webhook URL:

```text
https://your-render-url.onrender.com/webhooks/square
```

## Phase 4: Custom domain

After the Render URL works, add:

```text
app.yourdomain.com
```

Then update:

- Render custom domain
- Google OAuth redirect URI
- Square webhook URL
- `APP_BASE_URL`
- `GOOGLE_REDIRECT_URI`
