# Where To Find Provider IDs

Do not store secret tokens in this file. This is only for finding non-secret IDs.

## Square Location ID

In Square Developer:

1. Go to the Square Developer Console.
2. Open your application.
3. Choose Sandbox or Production.
4. Select Locations.
5. Copy the location ID for the location you want invoices tied to.

For a one-location business, this is usually the main/default location.

## Square Contract Template

DocuSign is no longer needed for the current plan.

In Square Dashboard:

1. Go to Orders & payments, Invoices & Payments, or Payments.
2. Open Contracts.
3. Open Templates.
4. Create a pressure washing service agreement template.

For the MVP, contract sending and signing can stay manual inside Square until we confirm whether Square exposes the needed contract automation through the developer API or webhooks.
